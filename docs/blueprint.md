# **App Name**: BM_EVAPORAÇÃO

## Core Features:

- Formulário de Entrada: Formulário para inserir dados do processo, como vazão, temperaturas, valores Brix e parâmetros dos equipamentos. Os campos aparecem dinamicamente com base nas escolhas do usuário (por exemplo, pré-aquecimento, edição de equipamentos).
- Cálculos Automáticos: Calcular automaticamente os campos, usando as fórmulas fornecidas, como 'DENSIDADE DO CALDO' e 'CONSUMO DE VAPOR (Total)'. Exibir os resultados em tempo real, conforme o usuário insere os dados.
- Visualização do Painel: Apresentar os principais indicadores de desempenho e os resultados calculados em um painel com gráficos, incluindo a evolução do Brix, a eficiência do efeito, a taxa de evaporação e a geração de vapor para cada efeito.
- Visão Detalhada do Resumo: Fornecer um resumo detalhado baseado em texto ('RESUMO') do processo de evaporação, mostrando os principais resultados para métricas como 'CALDO CLARIFICADO' e 'DESEMPENHO 1°EFEITO'.
- Avaliações Individuais dos Efeitos: Mostrar avaliações de texto detalhadas para cada um dos 5 efeitos de evaporação, incluindo as principais métricas, resultados calculados e uma avaliação qualitativa do desempenho. Formatar essas informações qualitativas usando IA generativa para funcionar como uma ferramenta para fornecer insights rápidos aos operadores.
- Compartilhamento via WhatsApp: Permitir o compartilhamento da avaliação de texto para cada efeito via WhatsApp. Também permitir o compartilhamento de uma avaliação geral combinada.
- Logo ISCAAL: Crie um logotipo com a palavra ISCAAL

## Style Guidelines:

- Cor primária: Dourado (#FFD700), simbolizando a valiosa saída do processo de evaporação.
- Cor de fundo: Preto (#000000), fornecendo um pano de fundo de alto contraste para a visualização de dados.
- Cor de destaque: Cinza escuro (#A9A9A9), fornecendo contraste nos principais elementos da interface do usuário sem ser distraente.
- Fonte do corpo e do título: 'Inter', uma fonte sans-serif com uma aparência moderna e neutra, para legibilidade de dados numéricos e resumos de texto.
- Use ícones padrão da indústria para etapas do processo, campos de entrada de dados e ações de compartilhamento. Os ícones devem ser monocromáticos para evitar distrações desnecessárias.
- Empregue um layout claro baseado em abas para separar o formulário de entrada de dados, as visualizações do painel, a visão geral do resumo e as avaliações detalhadas dos efeitos.
- Transições e animações sutis ao alternar entre as abas e exibir os cálculos.
